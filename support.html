MD-Reviewer Support

A native Markdown reader and editor for Mac, created by Allex Valentín.

Getting started

Open a .md or .markdown file. Switch between Reading, Source and Split. Select lines in Source and press Command-J to join them; blank paragraphs remain separate. Command-Z undoes the operation.

Printing and PDFs

Choose File → Page Setup for paper size and Settings → Page for margins and footers. Formatted sharing omits your local file path. Large table rows may continue onto the next page.

Recovery

File → Recover Unsaved Work restores an unsaved copy as a new file. File → Manage Recovery Copies lets you keep or explicitly discard retained copies. Saved originals are not replaced by recovery.

Reporting a problem

Include the app version, macOS version, steps, expected result and a disposable Markdown example. Do not send passwords or confidential documents.

Open the support issue tracker (a GitHub account is needed to post). Issues are public: do not upload confidential documents or personal data. For vulnerabilities, use private vulnerability reporting.
